STRELA

Politique de confidentialité

Strela — compteur de fléchettes X01 · version dev · mise à jour le 31 octobre 2026

Strela ne collecte, ne transmet ni ne partage aucune donnée personnelle.

Ce que Strela enregistre

Pour compter les parties, Strela garde sur le téléphone, et seulement là :

  • les joueurs que tu crées : pseudo, avatar (initiales, pictogramme ou photo recadrée), préférences de finition ;
  • les parties : chaque fléchette jouée, les manches, les vainqueurs, et les statistiques qui en découlent ;
  • les réglages : thème, sons, voix, vibrations, recherche de mise à jour.

Ces données sont dans le stockage privé de l'appli (ou du navigateur, pour la version web). Aucun compte, aucun identifiant, aucune publicité, aucun outil de mesure d'audience ni de suivi. Personne d'autre que toi n'y a accès, pas même l'auteur de Strela.

Photos

Une photo d'avatar est prise par l'appareil photo d'Android ou choisie dans la galerie, puis recadrée et réduite dans l'appli ; seule cette image réduite est gardée, sur le téléphone. Strela ne demande pas l'accès à l'appareil photo ni aux fichiers : c'est Android qui ouvre son appareil photo ou son sélecteur.

Sauvegarde

EXPORTER crée un fichier de sauvegarde (Téléchargements/Strela) que tu ranges où tu veux ; Strela ne l'envoie nulle part d'elle-même. IMPORTER relit un tel fichier, choisi par toi.

Réseau

  • Version Google Play : aucun accès à Internet (l'appli ne déclare pas la permission INTERNET).
  • Version GitHub (APK) : la seule connexion est la recherche de mise à jour, auprès de l'API de GitHub (dernière version publiée de Strela), au plus une fois par jour au lancement, ou quand tu touches RECHERCHER UNE MISE À JOUR ; elle se désactive dans les Réglages. Le téléchargement d'une nouvelle version, depuis GitHub, ne se fait que sur ton appui. Aucune de tes données n'est envoyée : GitHub ne reçoit que la demande elle-même (comme toute visite d'un site, avec l'adresse IP du téléphone).
  • Version web : la page est servie par GitHub Pages ; tes données restent dans le navigateur.

Suppression

Supprimer un joueur ou une partie l'efface du téléphone. Désinstaller l'appli efface toutes ses données (exporte une sauvegarde avant si tu veux les garder).

Enfants

Strela ne recueille aucune donnée, de personne, quel que soit son âge.
